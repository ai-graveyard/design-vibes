A CSS study inspired by Liquid Glass. This web approximation demonstrates layering, edge highlights and explicit appearance switching. It does not reproduce Apple's native real-time lensing, material merging or automatic legibility behavior. Reduced motion is respected. All interactions reset when the page reloads.
