# Embedded study fonts

Latin WOFF2 subsets distributed by Google Fonts, fetched on 2026-09-09. The original font files and individual SIL Open Font License notices are kept here. Exact source URLs, font weights and Unicode ranges are in `manifest.json`.

- Inter: Swiss study, glass studies and editorial utility text.
- Roboto: Material 3 study.
- Source Serif 4: editorial text.

`pnpm assets` embeds the font bytes, Unicode ranges and full license notices directly into the relevant standalone HTML. Keep the license notices when extracting or redistributing these files. Characters outside the included ranges use each demo's declared fallback stack; these are Latin typography studies, not a claim of identical CJK rendering across systems.
